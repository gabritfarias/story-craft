# StoryCraft 🎨📱
> Editor profissional de Stories para Instagram (9:16 / 1080x1920) focado em lojistas e e-commerce.

## ✨ Recursos
- **Formato Nativo 9:16 (1080x1920)**: Canvas de alta resolução com preview e exportação limpa em PNG.
- **Camadas de Texto & Tipografia**: Mais de 12 famílias tipográficas do Google Fonts, upload de fontes customizadas (.ttf/.otf), alinhamentos, sombras, contornos e cores.
- **Redimensionamento & Rotação**: Alças interativas para arrastar, girar e redimensionar caixas de texto e selos.
- **Selos & Adesivos de Oferta**: Badges comerciais com preços, parcelamentos e chamadas para ação.
- **Perfis de Estilização**: Salve e reutilize presets visuais com um clique.
- **Simulador Realista do Instagram**: Preview com Dynamic Island, relógio dinâmico e margens de segurança (Safe Zones).
- **Histórico Persistente**: Backend com banco SQLite (`better-sqlite3` + `Express`) para salvar artes definitivamente.
- **Design Mobile-First com Glassmorphism**: Interface responsiva com Side Drawers, Barra de Ações Rápidas, Botão Flutuante (FAB) e acabamento em vidro fosco.

## 🚀 Como Rodar Localmente

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/gabritfarias/storycraft.git
   cd storycraft
   ```

2. **Instale as dependências**:
   ```bash
   npm install
   ```

3. **Inicie o servidor**:
   ```bash
   npm start
   ```

4. **Abra no navegador**:
   Acesse `http://localhost:3000`
